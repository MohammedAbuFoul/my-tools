# TaskFlow — Code TODO Scanner & To-Do App

A full-featured desktop To-Do application and codebase `TODO` scanner built with **Go**, **Wails v2**, **SQLite**, and **sqlc**.

## Features

- **Codebase `TODO` Scanner**:
  - Recursively scans source files (skipping `.git`, `node_modules`, `vendor`, `dist`, `build`, binary files, etc.).
  - Finds `TODO` keywords, generates sequential persistent task IDs (`TASK (001)`, `TASK (002)`, ...), replaces `TODO` in-place with `TASK (XXX)` (preserving indentation, comments, and CRLF/LF line endings), and saves every task to SQLite with its source file path, line number, and snippet.
  - Supports **Dry Run Preview** before modifying files and tracks **Scan History**.
  - Works both inside the Wails GUI and via the CLI (`todo scan`).
- **Full To-Do Application**:
  - Create, edit, and delete tasks with auto-generated `TASK (XXX)` codes.
  - Status workflow (`To Do`, `In Progress`, `Completed`), priorities (`Low`, `Medium`, `High`, `Urgent`), categories, due dates (with overdue indicators), notes, and subtasks/checklists.
  - Search, priority filtering, sorting, completion progress tracking, and dark/light theme toggle.
  - Pure-Go SQLite (`modernc.org/sqlite`) with type-safe queries generated by `sqlc`.

## Project Structure

- `main.go` — Wails desktop entrypoint + `scan` CLI subcommand
- `app.go` — Wails bound methods exposed to the frontend
- `sqlc.yaml`, `db/schema.sql`, `db/queries.sql` — SQLite schema and `sqlc` queries
- `internal/db/` — Generated `sqlc` Go code
- `internal/store/` — SQLite database wrapper and transactional task numbering
- `internal/scanner/` — Codebase `TODO` scanner, replacer, and unit tests
- `frontend/dist/` — Desktop UI (HTML, CSS, JS)

## Commands

Run tests:
```powershell
go test ./...
```

Regenerate `sqlc` code after editing SQL queries:
```powershell
sqlc generate
```

Build the Wails desktop binary:
```powershell
wails build
```

Run in development mode:
```powershell
wails dev
```

Use the CLI scanner directly (shares the same SQLite database):
```powershell
.\build\bin\todo.exe scan --dry-run C:\path\to\code
.\build\bin\todo.exe scan C:\path\to\code
```
